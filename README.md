🎵 Moonbeat
Moonbeat is a browser-based rhythm game built with HTML, CSS, and JavaScript.

Players must press the correct keys as notes fall down the screen, earning points for accurate timing. The game is inspired by classic rhythm games and focuses on quick reactions, timing, and high-score chasing.

Features
Four playable lanes (A, S, D, F)
Falling note system
Real-time score tracking
Retro arcade-inspired gameplay
Simple and responsive controls
